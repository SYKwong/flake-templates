The `c-clang` template scaffolds a self-contained C playground with unit testing, mocking, standalone compilation via `clang`, and LSP integration.

For the GCC variant, see [C (GCC)](../c-gcc/).

## Toolchain & Dependencies

Provided declaratively via `c-clang/flake.nix` (`llvmPackages_23.stdenv`) across `x86_64-linux`, `aarch64-linux`, and `aarch64-darwin`:

- **`clang` 23 (`llvmPackages_23.stdenv`), `lldb` 23 & `gdb`**: Compiler and debuggers (`lldb` recommended on macOS).
- **Ceedling `1.2.2`** (Unity `2.7.2`, CMock `2.7.2`, CException `1.3.5`): Packaged via `pkgs.bundlerEnv` from `Gemfile`, `Gemfile.lock`, and `gemset.nix` and configured in `project.yml` to use `clang`.
- **`just`**: Task runner wrapping common test, build, clean, and gem update commands.

## Task Runner (`justfile`)

| Command | Action |
| :--- | :--- |
| `just` | Lists available recipes |
| `just test` | Runs `ceedling test:all` and updates `compile_commands.json` |
| `just test <target>` | Runs a single test suite (e.g. `just test test_example.c` or `just test example`) |
| `just build` | Runs `just test` (must pass), then compiles `src/*.c` with `clang -Wall -Wextra -g -Iinclude` into `build/main` |
| `just run` | Runs `just build`, then executes `./build/main` |
| `just clean` | Runs `ceedling clobber` and removes `build/` |
| `just update-gems` | Updates `Gemfile.lock` and regenerates `gemset.nix` via `bundler` + `bundix` |

## Editor & LSP Setup (`clangd`)

`project.yml` enables the `compile_commands_json_db` plugin, and `.clangd` sets:

```yaml
CompileFlags:
  CompilationDatabase: build/artifacts
```

Run `just test` once after creating a project so `build/artifacts/compile_commands.json` is generated for `clangd`.

## Ceedling Packaging & Updates

Instead of mutating global `~/.gem` state with `gem install` or committing gem binaries, Ceedling is packaged declaratively:

1. **`Gemfile` → `Gemfile.lock`**: `bundler` resolves exact gem versions (`~> 1.2.2`, allowing patch updates only).
2. **`Gemfile.lock` → `gemset.nix`**: `bundix` records the exact RubyGems SHA-256 hashes (only the manifest is committed to git).
3. **`nix develop` / `direnv`**: `pkgs.bundlerEnv` in `flake.nix` fetches those hashed gems into `/nix/store` and puts `ceedling` and `ruby` on `PATH` automatically.

To bump patch versions or add Ruby gems after editing `Gemfile`, run:

```bash
just update-gems
```

## Quirks

- **macOS debugging**: Use `lldb` for local debugging on macOS (`gdb` is included, but attaching to local macOS processes requires code-signing entitlements).
- **Supported systems**: Targets `x86_64-linux`, `aarch64-linux`, and `aarch64-darwin` (`x86_64-darwin` was dropped in `nixpkgs` 26.11).
- **`clangd` index**: `build/artifacts/compile_commands.json` is generated on demand when running `just test`.
